# Security Policy

## Supported Versions

Security updates are provided for the latest version available on the `main` branch.

| Version | Supported |
| -------- | --------- |
| main     | ✅ |
| older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly and privately.

### Preferred Contact Method

Send an email to:

**stefan-mihai@moga.doctor**

Please include:

- A detailed description of the vulnerability.
- Steps required to reproduce the issue.
- Potential impact of the vulnerability.
- Any proof-of-concept code, screenshots, or logs that may help demonstrate the issue.

### What to Expect

After submitting a report:

1. You will receive an acknowledgment as soon as possible.
2. The vulnerability will be reviewed and validated.
3. If confirmed, a fix will be developed and released.
4. You may be credited for the discovery unless you prefer to remain anonymous.

## Scope

This policy applies to the source code and infrastructure associated with:

- https://www.ip-address.ro/
- The GitHub repository for this project

### Out of Scope

The following are generally considered out of scope:

- Denial-of-service (DoS/DDoS) attacks.
- Social engineering attacks.
- Physical security attacks.
- Vulnerabilities in third-party services or dependencies that are unrelated to this project.
- Reports that require unrealistic user interaction.

## Security Best Practices

When contributing to this project:

- Validate and sanitize all user-supplied input.
- Avoid exposing sensitive server information.
- Keep PHP and server dependencies up to date.
- Follow the principle of least privilege for deployment environments.
- Report security concerns privately before opening a public issue.

## Disclosure Policy

Please do not publicly disclose security vulnerabilities until a fix has been made available and sufficient time has been given for deployment.

Thank you for helping keep this project and its users secure.
